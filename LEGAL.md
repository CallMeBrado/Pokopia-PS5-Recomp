## Game files and screenshots

The screenshots in the README document the port running on PS5. The repository does not
contain extracted game code, data, art, audio, text, shaders or keys, and none will be
accepted. The PlayStation button glyphs and the on-screen keyboard are drawn by scripts
in this repository (`ps5/scripts/gen-ps-glyphs.py`, `ps5/scripts/gen-ps-title.py`,
`ps5/scripts/gen-osk-font.py`). Playable game builds are not distributed. To use the port,
you need your own legally obtained copy of the game, which you dump and recompile yourself.
